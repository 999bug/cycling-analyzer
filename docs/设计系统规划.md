# 骑了么 · 设计系统规划与现状优化建议

> 2026-09-11 · 界面交互设计评审。本文档是**规划与诊断**，未经确认不改代码。
> 现状基线：版本 2.64.x，`src/index.css` 设计 token + `data-theme` 双主题 + 768px 抽屉布局。

---

## 一、设计原则

1. **数据优先**：这是数据密集型工具站，排版服务于「快速读数」——数字用等宽数字位（tabular-nums）、层级靠字重与颜色而不是靠装饰。
2. **运动感克制表达**：荧光绿 #b8e62e 是品牌资产，只做「强调」（主按钮、激活态、关键数字高亮），不做大面积铺色；大面积用中性色，让图表和数据本身成为视觉主角。
3. **移动优先**：先保证 320px 可用（单列、44px 触控目标），再向上增强到平板/桌面栅格。
4. **Token 单一来源**：颜色、间距、圆角、字号、动效时长全部走 CSS 变量；组件 CSS 不允许出现裸色值（现状有违反，见 §六）。

## 三、配色方案

### 3.1 品牌双色（现状保留）

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色（深色主题） | `#b8e62e` 荧光绿 | 主按钮、激活态、关键数字强调 |
| 主色上文字 | `#0d3b4c` 深蓝 | 荧光绿底上的文字 |
| 主色（浅色主题） | `#0d3b4c` 深蓝 | 同上语义，白底可读 |

### 3.2 背景与文字（现状保留，微调 tertiary）

| Token | 深色 | 浅色 | 说明 |
|-------|------|------|------|
| `--bg` | `#121417` | `#f5f6f8` | 页面底 |
| `--bg-surface` | `#1b1e23` | `#ffffff` | 卡片/侧栏 |
| `--bg-elevated` | `#232830` | `#ffffff` | 浮层/弹窗 |
| `--text` | `#e8eaed` | `#1a1d21` | 主文字（15.6:1 / 14.7:1 ✅） |
| `--text-secondary` | `#9aa0a6` | `#5f6368` | 次要文字（6.3:1 / 5.7:1 ✅） |
| `--text-tertiary` | `#6b7178` → **建议 `#7d838a`** | `#9aa0a6` → **建议 `#8a8f96`** | 辅助文字，现值不达标（见 §六 P0-2） |

### 3.3 新增：交互反馈 Token（解决硬编码问题）

```css
:root {
  --hover: rgba(255, 255, 255, 0.06);   /* 深色 hover 面 */
  --active: rgba(255, 255, 255, 0.10);  /* 深色按压面 */
}
:root[data-theme='light'] {
  --hover: rgba(13, 59, 76, 0.06);
  --active: rgba(13, 59, 76, 0.10);
}
```

落地后删除各文件里的 `rgba(255,255,255,0.06)` 与对应浅色覆盖规则。

### 3.4 数据可视化色板（P0：补浅色版）

现状 `theme/colors.ts` 常量只适配深色底。方案：常量拆成 `deep` / `light` 两套，由读取 `data-theme` 的 hook（或 CSS 变量 + Recharts `getCell` 按需取值）切换。

| 区间 | 深色主题（现状） | 浅色主题（新增） | 对比 |
|------|------|------|------|
| Z1 恢复 | `#4f8cff` | `#1a73e8` | 冷→暖渐强 |
| Z2 耐力 | `#34c759` | `#2e8b57` | |
| Z3 有氧 | `#ffd60a` | `#c9a800` | 白底可辨 |
| Z4 阈值 | `#ff9f0a` | `#e67300` | |
| Z5 冲刺 | `#ff453a` | `#d32f2f` | |

注意：深色主题下 Z3 `#ffd60a` 与 Z4 `#ff9f0a` 色相接近，色觉障碍用户难区分，建议 Z4 改偏橙红 `#ff7a1a` 或给 Z3 加纹理——与现有「强度递进」直觉一致即可。

### 3.5 对比度体检结论（WCAG 2.2 AA）

- ✅ 主文字、次要文字、荧光绿/深蓝组合：全部达标
- ❌ `--text-tertiary` 深色 3.4:1 / 浅色 2.5:1（12–13px 小字场景必须 ≥4.5:1）→ 调亮/调深一档即可
- ⚠️ 浅色主题 `--warning #e67300` 作小字文字时 3.2:1：仅作图标/色块底 OK，避免作 14px 以下文字色
- ✅ 图表色块作为 UI 组件边界 ≥3:1：浅色版色板落地后达标

## 四、字体方案

### 4.1 字体栈（现状保留，补数字优化）

```css
font-family: system-ui, -apple-system, 'Segoe UI', Roboto,
  'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif;
```

系统栈是对的（零加载成本、原生质感）。唯一要补的：

```css
/* 所有指标数字容器统一加：等宽数字位，跳动数据不抖列 */
.metric-value, .stat-card__number, .chart-tooltip {
  font-variant-numeric: tabular-nums;
  letter-spacing: 0.01em;
}
```

不引入 webfont：数据工具站首屏速度 > 字体个性，且中文 webfont 动辄数 MB。

### 4.2 字号刻度（新增 Token，替换散落硬编码）

| Token | 字号/行高 | 字重 | 用途 |
|-------|-----------|------|------|
| `--font-display` | 28px / 1.2 | 600 | 核心指标大数字（配 tabular-nums） |
| `--font-h1` | 24px / 1.3 | 600 | 页面标题 |
| `--font-h2` | 16px / 1.4 | 600 | 区块/卡片标题（现 14px 偏弱，升 16 强化层级） |
| `--font-body` | 14px / 1.6 | 400 | 正文、表格、图表轴 |
| `--font-secondary` | 13px / 1.5 | 400 | 次要说明 |
| `--font-caption` | 12px / 1.5 | 400 | 辅助提示、版本号 |

刻度比率约 1.15–1.33，全部 4px 倍数，符合 8px 基线体系的精简版。字重只用 400/500/600 三档（600 仅标题与数字）。

## 五、移动优先布局规划

### 5.1 断点体系（收敛为 4 档）

| 断点 | 宽度 | 布局行为 |
|------|------|----------|
| 基线 | 320–575px | 单列；卡片内部指标降为 2 列；侧栏=抽屉 |
| 手机横屏/小平板 | 576–767px | 单列为主，统计卡可 2 列；侧栏=抽屉 |
| **平板（现 768px 保留）** | 768–991px | 侧栏常驻 200px；内容区 16px 边距 |
| 桌面 | 992px+ | 侧栏 220px；内容区 24px 边距 |
| 宽屏（新增） | 1200px+ | 内容区 max-width 1280px 居中，防超宽拉伸 |

现状 900px（dashboard 单列→三列）并入 992px 档，减少孤点。

### 5.2 移动端关键行为

- **导航**：现方案「顶栏汉堡 + 抽屉」可用但藏了 2 层。**建议（需拍板）**：新增移动端底部 Tab Bar 承载 4 个高频页（仪表盘/记录/统计/路线），次级页（热力图、训练计划、更多）留在抽屉——数据类 App 高频页面切换成本应 ≤ 1 次点击。
- **触控目标**：所有可点元素 ≥44×44px。现状菜单按钮 40px、图表切换按钮 `padding:3px 10px` 偏小，热区补到 44px（视觉可不变，用 padding/伪元素扩热区）。
- **图表高度**：`--chart-height` 变量，移动 180px / 平板 220px / 桌面 260px。
- **地图页**：已做 flex 撑满（2.64.0），保留。
- **手势**：抽屉支持边缘右滑关闭（当前只有遮罩点击）；列表项滑动操作可作为 v2。

### 5.3 栅格规则

- 卡片网格统一 `repeat(auto-fill, minmax(280px, 1fr))`，免媒体查询自适应列数，替代散落的 `@media` 改列逻辑。
- 页面统一留白 Token：移动 16px / 平板 16px / 桌面 24px（现状已对，固化为变量）。

## 六、优化清单（分批落地建议）

### P0（无障碍硬伤，建议先做）

1. **图表色板浅色适配**：`theme/colors.ts` 拆 deep/light 两套；顺带处理 Z3/Z4 区分度。涉及各图表组件取色处。
2. **`--text-tertiary` 对比度修正**：`index.css` 两行改动，全局生效。深色 `#6b7178 → #7d838a`，浅色 `#9aa0a6 → #8a8f96`。

### P1（一致性，中期）

3. **hover/active Token 化**：新增 `--hover`/`--active`，批量替换 50+ CSS 文件里的硬编码（可全局搜索 `rgba(255, 255, 255, 0.06)` 定位）。
4. **字号刻度 Token 化**：按 §4.2 新增 6 个变量，替换硬编码字号；`.chart-card__title` 14→16px。
5. **断点收敛**：900px→992px，1200px 加 max-width；卡片网格改 `auto-fill/minmax`。
6. **触控目标 44px**：菜单按钮、图表切换、图例等小按钮补热区。

### P2（体验增强，择机）

7. **`<meta theme-color>` 动态化**：applyTheme 时同步改 meta（深 #121417 / 浅 #f5f6f8），PWA 状态栏颜色跟随主题。
8. **图表高度响应式**：`--chart-height` 变量三档。
9. **移动端底部 Tab Bar**：需要产品拍板页面取舍，建议出可点击原型后再实施。
10. **CSS 归并**：50+ 个组件 CSS 里的重复模式（卡片头、toggle、空态）抽公共类（`.card`、`.segmented-control`、`.empty-state`），减重复代码约 1/3。建议在新页面先用、老页面渐进替换。
