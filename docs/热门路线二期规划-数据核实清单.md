# 热门路线二期规划 — 数据核实清单

> 状态：**北京 22 条已于 2.70.0 接入网站（里程碑 1）**；全国 6 条待接入（里程碑 2）。
> 原始规划口径：按用户 2026-09-11 指示先核实数据（北京 ≥20 条），三级来源标注；
> 页面改版原型：`docs/prototypes/routes-page-redesign.html`（已随 2.70.0 实现）。

## 0. 总体方案

- **数据诚实性红线不变**：每条路线的里程/爬升必须有据可查，按来源可信度分三级标注：
  - **A 级（官方）**：政府官网/政府主办赛事规程/官方景区发布
  - **B 级（权威媒体/平台）**：野途网、北京旅游网、捷安特官方骑游地图等
  - **C 级（社区码表口径）**：骑友坡度表/路书，两个及以上独立来源相互印证时采用，UI 标注「骑行社区码表口径」
- **几何生成不变**：接入阶段用 `scripts/generate-curated-routes.mjs`（Overpass 路网 + Dijkstra 选路，排除高速/隧道），锚点坐标一律 OSM 反查，禁止手写。
- **难度口径**：1 休闲 / 2 新手入门 / 3 中级进阶 / 4 硬核挑战 / 5 极限挑战。

## 3. 页面改版原型（待评审）

`docs/prototypes/routes-page-redesign.html` —— 要点：

1. 「我的路线 / 热门路线」从窄页签升级为**大分区切换**（带副标题说明），热门路线强调「发现」属性
2. 热门路线 = 地区筛选 chips + 路线卡片网格（名称 → 类型/难度 → 里程爬升 → 区域卖点）+ 选中详情面板（介绍/提示/来源/免责声明）
3. 我的路线 = 现有地图 + 统计 + 列表，交互不变，仅重排布局
4. 移动优先：单列、地图在上；桌面双栏（地图+卡片 | 详情侧栏）；≥992px 三列卡片
5. 配色沿用现有 token（深蓝底 + 荧光绿），原型内为示意值，实施时替换
