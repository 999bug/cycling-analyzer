设计说明（v2 修订点）

  • 去掉行内标记：表格不再显示「脏？」徽标，列表保持干净；脏数据只在删除确认时按阈值识别。
  • 阈值用户自设：删除确认弹窗顶部提供阈值输入（距离 < N km 或时长 < N 分钟，默认 5km/10min），修改后下方疑似脏数据列表实时更新；阈值仅本次删除弹窗内生效。
  • 「介于」区间：条件新增「介于」，选择后出现「数值 至 数值」两个输入框，闭区间匹配（含边界）；日期字段同理为「起始日期 至 结束日期」。
  • 条件 chips 前移：已生效的自定义筛选条件以 chip 形式展示在「类型」下拉右侧（主筛选栏内），点 × 移除单个条件，与搜索/月份/类型并列。
  • 预设持久化：「保存为预设」命名后存入 localStorage；「已保存的筛选预设」下拉可随时套用、删除；刷新页面后预设与当前生效条件都会恢复（本原型 localStorage 真实生效，可刷新验证）。排序状态同样持久化。
  • 实现上条件数据结构为 { field, op, value, value2? }，预设为 { name, conditions[] }；与现有搜索/月份/类型筛选叠加生效。
