# 2026-09-13 精选路线全国补录（二轮）

## ⛔ 事故：并发入库写坏几何数据（必记）

为提速同时开了两个 `curate-batch`（一个正式写、一个 --dry），结果
`src/features/curatedRoutes/nationalTracks.ts` 被覆盖成只剩 1–2 个 key——
**123 条已上线几何丢失**。

根因链：
1. `generate-curated-routes.mjs` 的 `readExistingOutput()` 用 try/catch 包住，
   **解析失败就静默 `return {}`**；
2. 两个进程「读-改-写」交错，其中一个读到半截文件 → 解析失败 → 拿到空对象；
3. 空对象 + 新几何 → 整份写回 → 旧数据蒸发。

三处加固（已提交 fb6d168）：
- `readExistingOutput` 找不到标记/解析失败 → **直接抛错中止**，绝不静默兜底
- 入库整段（tracks / 数据条目 / 测试文件）加 **mkdir 文件锁** `withFileLock`
- tracks / 数据文件改 **原子写**（同目录 `.tmp-<pid>` + `renameSync`）

恢复手段：`git show HEAD:...nationalTracks.ts` 取回上一版，再按
`.tmp/curate/<id>/geometry.json` 补回新几何（每条都落盘过，能全量重建）。
→ **教训：任何「读-改-写」公共数据文件的脚本，都不许并发跑；临时产物目录的
落盘副本是最后的保险。**
