- **实现**：①新纯函数模块 `src/features/activity/segmentsProfile.ts`（抽稀 + 60m 窗口坡度平滑 + alt0-4 分档海拔字段 + segmentIndex + UCI 徽章锚点）；②`SegmentsSection.tsx` 手绘 SVG → ComposedChart，每档一条 Line（dataKey=altN 字符串键避开函数式 dataKey 返回 undefined 的 TS 限制），ReferenceArea 分段色带、ReferenceDot UCI 徽章、自定义 Tooltip 内容组件（经 content 元素透传 segments/distanceUnit）。
- **重要发现/修复**：recharts 3 的 `state.activeTooltipIndex` 是**字符串**（如 '6'），MetricChart 原 `typeof === 'number'` 判断自 recharts 3 升级后失效 → 六图悬停不再上报时间戳，共享时间轴联动（地图圆点等）全部静默失效。新增 `timeline.ts` `activeTooltipIndexToNumber()` 归一化，MetricChart 与 SegmentsSection 共用。
- **测试坑**：①recharts 3 mousemove 默认 raf 节流（throttleDelay:'raf'），jsdom 断言 Tooltip 必须 `await waitFor()` 等一帧；②SVG 刻度文本被 tspan 拆分（'5.0km' 无空格），断言改查 `.recharts-cartesian-axis-tick` 节点；③合成 fixture 的经纬度若线性变化，Douglas-Peucker 会把中间点全部抽稀（剖面只剩 2 端点），需加 ±0.0005 纬度抖动。
