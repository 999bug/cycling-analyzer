## .git 事故与恢复 + 文档提交
- 用 `git stash push` 做测试对照时命令被 SIGTERM 中断，`.git/refs/` 目录与近期 loose 对象被连带删除（用户反馈此类事故已多次）。恢复链路：`mkdir .git/refs/{heads,tags,remotes}` → 从 reflog 找到最后提交 → 远端恰好有同 commit → fetch 后 `git update-ref refs/heads/main` → `git pack-refs --all --prune` 固化。
- 教训：**永不用 git stash 做临时对照**（改用 cp 文件到临时目录或 diff 备份）；恢复后立即 pack-refs 防复发；提交时若报 "invalid object ... for '文件'" 说明索引指向的 blob 丢失，`git reset` 重建索引再 add 即可（文件在磁盘上没丢）。
