## [BF] 迁移完成横幅无限刷新循环修复（2.47.2，commit c0c17ca）

- 线上严重 bug：2.47.0 上线后每次打开页面都自动刷新。根因：`runRecordsMigration` 在状态已是 done（上个会话已完成）时仍返回 `'done'`，MigrationBanner 误判为「本次刚完成」→ 显示完成横幅 → 1.5s 后 reload → 死循环。

- 教训：当时只在 mock 场景测了「从未迁移→完成→刷新一次」，没有测「已完成状态再次启动」的幂等静默路径；补了回归用例锁死。
- 经验：两个并行 Edit 调用同一文件时第二个会静默丢失（类型联合编辑没落盘，靠 tsc 抓回），同文件多处修改要串行或一次改完。
